# Competitive Analysis Process

## Step 1: Define Comparison Criteria

Identify what matters:
- Features and capabilities
- Performance and scalability
- Pricing and ROI
- User experience
- Community and ecosystem
- Support quality
- Security and compliance
- Integration options

## Step 2: Gather Information

For each option, research:
- Official documentation
- Pricing pages
- Feature comparison tables
- Customer reviews
- Performance benchmarks
- Community discussions
- Case studies

## Step 3: Create Comparison Matrix

Table format:
| Criteria | Option A | Option B | Option C | Winner |
|----------|----------|----------|----------|--------|
| Feature 1 | ✅ | ✅ | ❌ | A/B |
| Feature 2 | Advanced | Basic | Advanced | A/C |
| Price | $$$$ | $$ | $$$ | B |
| Support | 24/7 | Community | Business hrs | A |

## Step 4: Score Each Option

Rating scale (1-10):
- **Overall**: Sum of weighted criteria
- **Value**: Performance-to-cost ratio
- **Recommendation**: Best for this use case

## Step 5: Present Recommendations

For each use case, recommend the best option:
- "If budget is tight: Option B"
- "For enterprise: Option A"
- "For startups: Option C"

## Format

```markdown
## Comparison: [Options]

### Matrix
[Table above]

### Detailed Comparison

#### Feature Set
- Option A: [Features]
- Option B: [Features]
- Option C: [Features]

#### Performance
- Benchmarks and metrics
- Scalability assessment
- Real-world performance

#### Pricing
- Cost structure
- Total cost of ownership
- ROI analysis

### Recommendation
[Clear winner with reasoning]

### Trade-offs
[What you gain/lose with each choice]
```

## Evaluation Checklist

- [ ] Defined all relevant criteria
- [ ] Researched all options thoroughly
- [ ] Created comparison matrix
- [ ] Considered multiple use cases
- [ ] Identified trade-offs
- [ ] Provided clear recommendation
- [ ] Cited sources
- [ ] Explained reasoning
