# Deep Research Process

For complex research tasks that require comparing options, analyzing trends, or synthesizing information.

## When to Use

- "Compare X vs Y vs Z" (products, tools, frameworks)
- Market analysis or industry trends
- Evaluating solutions for a problem
- Understanding pros/cons of approaches
- Research with multiple sources and perspectives

## Research Framework

### 1. Define the Research Question
- Clarify scope: What exactly needs researching?
- Identify key criteria for comparison
- Note any constraints (budget, scale, team size)

### 2. Gather Information
- Search documentation and official sources
- Look for real-world comparisons and benchmarks
- Find community experiences (GitHub issues, Reddit, HackerNews)
- Check pricing, performance metrics, adoption rates

### 3. Structure Findings
Organize by categories:
- **Features**: What does each option do?
- **Performance**: Speed, scalability, resource usage
- **Cost**: Pricing model, free tiers, enterprise support
- **Ecosystem**: Community, plugins, integrations
- **Maturity**: Stability, maintenance, adoption
- **Learning Curve**: Documentation, tutorials, examples

### 4. Synthesize & Recommend
- Create comparison matrix (pros/cons)
- Highlight best choice for different scenarios
- Explain trade-offs and reasoning
- Suggest next steps (trial, POC, migration plan)

## Output Format

```markdown
# Research: [Topic]

## Executive Summary
[1-2 paragraph overview of key findings]

## Comparison Matrix
| Criteria | Option A | Option B | Option C |
|----------|----------|----------|----------|
| Feature 1 | ✅ | ✅ | ❌ |
| Cost | $$ | $$$ | $ |
| Maturity | ★★★★★ | ★★★★ | ★★★ |

## Detailed Analysis

### Option A
- **Pros**: [list]
- **Cons**: [list]
- **Best For**: [use cases]

### Option B
[...]

## Recommendation
[Clear recommendation with reasoning based on research]

## Sources
- [Official docs]
- [Benchmark/comparison]
- [Community feedback]
```

## Examples

**Good Research Task:**
- "Help me choose between Vercel, Netlify, and Railway for deploying my Next.js app"
- "Compare Supabase, Firebase, and Neon for a startup"
- "Research AI frameworks: LangChain vs LlamaIndex vs CrewAI"

**Not Research Tasks:**
- Simple factual questions (use documentation lookup)
- General explanations (use general knowledge)
- Code debugging (use code analysis skill)
